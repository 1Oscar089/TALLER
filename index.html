Conexión a Google Sheets

La URL canónica vive en la constante APPS_SCRIPT_URL al inicio del script de este index.html: edítala una sola vez y funcionará igual en todos tus dispositivos, sin configurar nada más. Lo que guardes aquí es solo un override local de este navegador, por si quieres probar otra implementación sin tocar el código.

Nuevo módulo

Se escribirá una fila en la hoja INDEX y se creará una hoja propia para los datos del módulo. El archivo se resolverá dentro de pages/ automáticamente: escribe solo el nombre, ej. acortador.html.
